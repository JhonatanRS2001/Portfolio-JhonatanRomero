TERRABROKER - Plataforma Cloud de Gestión de Carteras de Inversión

Plataforma donde podremos comprar activos cripto como BTC, ETH, SOL, ADA y DOGE. A su vez también podremos seguir nuestras posiciones y ver gráficos en directo de los activos más importantes.

Desarrollado con Java 17, Spring Boot, Hibernate y Thymeleaf. Desplegado en AWS (EC2, RDS MySQL, Route 53).

TERRABROKER - Infrastructure as Code (Terraform)

Migración completa de la infraestructura de TerraBroker a Terraform (IaC). Lo que antes eran 30+ clicks manuales en consola AWS, ahora se despliega con un simple terraform apply.

Arquitectura implementada:

  • VPC multi-AZ en eu-west-1 (subnets públicas y privadas)
  • EC2 instance para la aplicación
  • RDS MySQL en subnet privada
  • Route 53 para gestión DNS
  • Security Groups con principio de mínimo privilegio
